Firebase Firestore সিকিউরিটি রুলস (Security Rules)

Admin Panel থেকে ব্রডকাস্ট এবং ফোন থেকে ডিভাইস মডেল ডেটা সেভ করার জন্য Firebase Console-এ নিচের নিয়মগুলো নিশ্চিত করুন:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 1. Devices Telemetry (Phone models & install counting)
    match /devices/{deviceId} {
      allow read, write: if true;
    }

    // 2. In-App Updates broadcast
    match /app_updates/{updateId} {
      allow read, write: if true;
    }

    // 3. Authenticated User Data
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

কোথায় সেট করবেন?

  1. Firebase Console (console.firebase.google.com)-এ যান।
  2. আপনার app-66a7d প্রজেক্টে ক্লিক করে বাম মেনুর Firestore Database-এ যান।
  3. উপরে থাকা Rules ট্যাবে ক্লিক করে এই কোডটি পেস্ট করে Publish করে দিন।
